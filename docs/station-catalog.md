# 国内电台目录

> 发布快照：2026-09-05 · Radio OS 1.0

固件内置 **542 个已验证公开 MP3 直播流**：537 个蜻蜓公开直播地址，另加香港电台
Radio 1–5。目录编译进 Flash，浏览、分页与筛选不依赖 Radio Browser 或运行时目录服务。

## 验证口径

1. 从公开社区列表收集 808 个不重复的蜻蜓频道 ID，仅作为候选集合。
2. 对每个候选地址实际发起网络请求，要求成功响应并读到 MP3 数据；2026-09-06 发布前复检中
   537 个蜻蜓流通过，17 个持续返回 HTTP 404 的旧地址已从目录和生成器中剔除。
3. 对通过项查询蜻蜓公开网页元数据，全部取得正式台名、地区、城市与内容分类。
4. 香港电台 Radio 1–5 分别验证为可读取的 `audio/mpeg` 流。
5. 生成 `main/station_catalog.inc`，运行时不再拉取第三方目录。

公开流可能随电台或平台调整而变化，因此这里的“已验证”指生成快照时通过，不表示永久可用；
播放器会对临时断流自动重连。当前解码器只收录 MP3，HLS、AAC/AAC+ 不进入目录。

## 分类与地区

内容分类包括：综合、资讯、音乐、交通、财经、文艺、生活、体育、少儿、方言。
地区以全国级和省级行政区为主，香港单列；筛选可将地区与内容类型组合使用。

目录中的主要数量分布可通过串口 `regions` 和 `categories` 查看。当前较多的地区包括河北、
江苏、浙江、广东、山东；内容以综合、交通、资讯、音乐为主。无匹配结果时界面会显示空态，
而不是发起网络搜索。

## 更新目录

生成工具：`tools/generate_station_catalog.py`

```bash
python3 tools/generate_station_catalog.py \
  --verified-tsv /tmp/esp-radio-catalog.tsv \
  --enriched-tsv /tmp/esp-radio-enriched.tsv \
  --output main/station_catalog.inc
```

TSV 是采集与联网验证阶段的中间结果，不提交仓库；生成的 C 数据文件会随固件发布。

## 数据来源

- 候选频道 ID：`gaotianliuyun/gao` 项目公开的 `radio.txt`
- 台名、地区与分类：蜻蜓开放平台及其公开网页接口
- 香港电台：RTHK 官方公开直播入口

社区列表只用于发现候选项，最终是否进入产品目录以本次实际拉流和官方元数据验证为准。
