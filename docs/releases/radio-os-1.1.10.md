# Radio OS 1.1.10

修复香港电台第 1–5 台及普通话台在部分 DNS 环境中无法连接的问题。
六路 MP3 地址改用同一服务的公开 DNS CNAME 别名，不固定 CDN IP，不更改全局 DNS 或增加代理。
台库仍为 543 台，其他 537 台、频道名称、排序及分类不变，目录生成器同步更新。

## 验证与限制

- 开发板上六路均通过短时连接、MP3 解码和持续下载检查；自检通过。
- 原始 Akamai HLS 入口可访问，但当前播放器没有 HLS/TS/AAC 支持，本版仍使用 MP3。
- 重复切台测试出现过一次旧会话未及时退出、选台失败；本版没有修改播放器任务生命周期，此问题仍待排查。
- 已有收藏或最后电台若保存旧完整 URL，需要从新版台库重新选择或收藏。
- 本次不包含 CYD2432 移植。详细证据见 `docs/rthk-playback-investigation.md`。

## 升级

OTA 保留 Wi-Fi、收藏和本机设置。`0x0` 整合镜像用于全新烧录，会清除 NVS 中的 Wi-Fi、收藏等设置。
