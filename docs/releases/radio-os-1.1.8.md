# Radio OS 1.1.8

## 随机换台

- Wi-Fi 左侧新增可点击的随机图标，开启后高亮，重启后记住选择；默认关闭。
- 开关不打断当前播放。开启后，下一台在当前播放来源内随机选择，避开当前流地址；上一台回退最近 12 次随机切台记录。
- 支持推荐、收藏和筛选后的全部电台。只有当前台时不重连；收藏为空时回退到推荐。
- 直接选台或切换模式会清空历史；历史与目录筛选不跨重启保存。
- 顶部时间与睡眠倒计时上下排列，兼容 12/24 小时制。

## 界面维护与修复

- 按播放、列表、设置、Wi-Fi、信息页等职责拆分界面代码，独立管理应用状态和偏好保存，并补充关键中文注释。
- 保留原有设置格式，改进后台事件与界面任务之间的数据传递、页面销毁和主题重建。
- 修复主题色按钮装饰圆点、触摸诊断十字标记拦截点击的问题。
- 增加应用逻辑测试和开发板界面回归工具；发布构建关闭触摸注入及截图测试接口。

## 验证

应用逻辑、设置兼容性、构建及开发板自检通过。随机切台/历史、重启保存、明暗主题、睡眠与唤醒、相邻按钮和真实网络播放已验证。画面与点击验证使用开发板 LVGL 渲染和输入注入；未做真人触摸精度、主观听音或多小时稳定性测试。

## 升级与烧录

OTA 升级保留 Wi-Fi、收藏和本机设置。`radio-os-1.1.8-0x0.bin` 用于全新烧录，**会清除 NVS 中的 Wi-Fi、收藏等本机设置**。保留设置可使用 OTA，或在确认设备分区布局后只写应用分区；本仓库独立布局的 `ota_0` 位于 `0x20000`。
