## 板子身份

| 项 | 值 |
|---|---|
| 厂商 / 型号 | LCDwiki（乐视科技）2.8inch ESP32-S3 Display |
| SKU | **ES3C28P**（带电容触摸）/ ES3N28P（无触摸） |
| 主控 | ESP32-S3R8（QFN56） |
| 屏 | 2.8" IPS，240×320，驱动 IC **ILI9341V**，4 线 SPI |
| 屏模组 | QD2833（18P 0.8mm FPC 焊接口） |
| 触摸 | **FT6336G** 电容触摸，I²C @ **0x38** |

| 功放 | **SC8002B**（原理图实物；厂商给的是 pin 兼容的 FM8002E 数据手册） |
| 麦克风 | LMA2718B381-OA7 下进式模拟 MEMS |
| RGB 灯 | XL-5050RGBC-**WS2812B**，单线，**5V 供电** |
| 充电 | TP4054，R12=3.3K → 实测约 290mA |
| LDO | 2× ME6217C33M5G（系统一路 + 音频独立一路） |

```

USB mode: USB-Serial/JTAG
```

**内存配置：16MB QSPI Flash（外置 W1）+ 8MB OPI(octal) PSRAM（片内）**。
这是 N16R8 配置，构建时 PSRAM 必须选 **Octal** 模式，Flash 选 **QIO/DIO**。

## 引脚分配（权威表）

方向一律**从 ESP32-S3 视角**描述。

### 液晶屏 ILI9341V（4 线 SPI）

| 信号 | GPIO | 说明 |
|---|---|---|
| TFT_CS | **10** | 片选，低有效 |
| TFT_DC / RS | **46** | 命令/数据选择。高=数据，低=命令 |
| TFT_SCK | **12** | SPI 时钟（模式 0：CPOL=0, CPHA=0） |
| TFT_MOSI | **11** | SPI 写数据 |
| TFT_MISO | **13** | SPI 读数据 |
| TFT_RST | **CHIP_PU** | ⚠️ **与 ESP32 复位共用**，没有独立的屏复位 GPIO |
| TFT_BL | **45** | 背光。**高=亮，低=灭**；上电默认灭。可直接喂 PWM 调光 |

背光电路：GPIO45 → Q4(BSS138) 栅极 → 拉低屏背光 LED 负极。R33=5R6 限流。

⚠️ 这块是 **IPS 版**面板，驱动初始化后必须发 `INVON`（反显开），否则整屏黑白反相。见 [坑 9](#9-ips-版-ili9341-必须开反显)。

### 电容触摸 FT6336G

| 信号 | GPIO | 说明 |
|---|---|---|
| TP_SCL | **15** | I²C 时钟（共享总线） |
| TP_SDA | **16** | I²C 数据（共享总线） |
| TP_RST | **18** | 复位，低有效 |
| TP_INT | **17** | 触摸中断，触摸时输出低 |

I²C 从地址 **0x38**。上拉 R29/R30 = 4.7K（板载，不用再加）。

### I²C 总线（一条总线，三个去处）

**SCL = GPIO15，SDA = GPIO16**，以下全部挂在同一条总线上：

- FT6336G 触摸 @ `0x38`
- ES8311 编解码 @ `0x18`
- 板上 4P「IIC 外设接口」座子（对外扩展）

> GPIO15/16 在 S3 上同时是 `XTAL_32K_P/N`。本板**没有 32.768kHz 晶振**，
> 所以这两个脚可以自由用作 I²C。反过来说，本板**无法接外部 32K 晶振**。

### 音频（ES8311 + SC8002B）

| 信号 | GPIO | 方向（ESP32 视角） | 说明 |
|---|---|---|---|
| AUDIO_EN | **1** | 输出 | 功放使能。**低=开声，高=静音**；板载 R26 10K 上拉到 3V3，**上电默认静音** |
| I²S MCLK | **4** | 输出 | 主时钟 |
| I²S BCLK | **5** | 输出 | 位时钟 |
| I²S LRCK/WS | **7** | 输出 | 声道选择。高=右，低=左 |
| **I²S DOUT** | **8** | **输出** | → ES8311 `DSDIN`（喇叭/播放通路） |
| **I²S DIN** | **6** | **输入** | ← ES8311 `ASDOUT`（麦克风/录音通路） |

⚠️ **GPIO6/GPIO8 极易搞反**，详见文末。

功放最大 1.5W@8Ω / 2W@4Ω（5V 供电）。喇叭走 JP3 2P 1.25mm 座子，差分输出 SP+/SP-。

### MicroSD（SDIO 4 位）

| 信号 | GPIO |
|---|---|
| CLK | **38** |
| CMD | **40** |
| D0 | **39** |
| D1 | **41** |
| D2 | **48** |
| D3 | **47** |

板载 10K 上拉（R34~R37）。走 SDIO 而非 SPI，比 SPI 快。
注意 GPIO39~42 是 JTAG 脚（MTCK/MTDO/MTDI/MTMS），用了 SD 卡就没法接外部 JTAG 调试器
（但 USB-Serial/JTAG 仍可用）。

### 其它板载外设

| 功能 | GPIO | 说明 |
|---|---|---|
| RGB LED（WS2812B） | **42** | 单线；**灯珠是 5V 供电**，3.3V 电平直驱，多数情况能点亮但属于超规格 |
| 电池电压 ADC | **9** | ADC1_CH8。R14/R15 = 200K/200K 分压 → **实际电压 = 读数 × 2** |
| BOOT 按键 | **0** | R10 上拉；按住上电/复位进下载模式。平时可当普通按键 |
| RESET 按键 | CHIP_PU | 同时复位 ESP32 和屏 |
| UART0 TX | **43** | 4P 座子引出；不用串口时可当普通 IO |
| UART0 RX | **44** | 同上 |
| USB D− | **19** | 内置 USB-Serial/JTAG，接 Type-C |
| USB D+ | **20** | 同上 |

### 可自由使用的 IO

板上「扩展输入引脚」4P 座子引出：**GPIO2、GPIO3、GPIO14、GPIO21**。
（GPIO2/3 = ADC1_CH1/CH2，GPIO14 = ADC2_CH3，GPIO21 无 ADC。四个都带 TOUCH 功能除 21 外。）

再加上有条件可用的：
- **GPIO15/16** — 只在不用触摸也不用音频时才能当普通 IO
- **GPIO43/44** — 不用 UART0 时可当普通 IO

### 被占死的 IO（别碰）

- GPIO26 — 片内 OPI PSRAM 片选
- GPIO27~32 — 外部 QSPI Flash（CS/CLK/D0-D3）
- GPIO33~37 — 片内 OPI PSRAM DATA4-7 + DQS

## 板上接线座（丝印实测）

以下顺序读自厂商接口定义图（`ES3C28P-05.png`，见厂商页面）的 PCB 丝印，
**三角标记 ▲ 指示 pin 1**。接线前最好再对着实物丝印确认一眼。

### 扩展引脚（4P 1.25mm）

| pin | 信号 |
|---|---|
| 1 ▲ | GPIO2 |
| 2 | GPIO3 |
| 3 | GPIO14 |
| 4 | GPIO21 |

⚠️ 这个座子**只有信号没有电源和地**，接外设要另外从 IIC 座子取 3.3V/GND。

### IIC 外设接口（4P 1.25mm）

| pin | 信号 |
|---|---|
| 1 | 3.3V |
| 2 | GND |
| 3 | GPIO15（SCL） |
| 4 | GPIO16（SDA） |

和板载触摸、ES8311 是同一条总线，挂外设时注意地址别撞（已占用 `0x38`、`0x18`）。

### 串口（4P 1.25mm，丝印 UART）

| pin | 信号 |
|---|---|
| 1 ▲ | 5V |
| 2 | GND |
| 3 | TXD（GPIO43，ESP32 发送） |
| 4 | RXD（GPIO44，ESP32 接收） |

丝印的 TXD/RXD 是**ESP32 视角**。接 USB-TTL 时要交叉：
适配器 TX → 座子 RXD，适配器 RX → 座子 TXD。

### 电池（2P 1.25mm，丝印 BAT）

丝印上标了 `+`。**接反会烧板**，插之前务必确认。

### 喇叭（2P 1.25mm，丝印 SPEAKER）

差分输出 SP+/SP−，**不要接地**，也不要和其它音源共地。
用户手册提醒接线端子需垂直插入。

### 触摸屏 FPC（P1，6P 0.5mm，板内）

丝印顺序 `1.VDD 2.SCL 3.SDA 4.INT 5.RST 6.GND`。
这是板载电容触摸屏的排线口，正常不用动。

## 电源

- Type-C 输入 5V。整板：只开屏 ≈140mA；屏+喇叭+充电 ≈560mA
- 两路独立 3.3V LDO（ME6217C33M5G，最大 800mA）：一路给音频，一路给其余电路
- 电池：3.7V 锂聚合物，2P 1.25mm 座子，**注意正负极**
- 电源路径：Q3（P-MOS）自动切换。插 Type-C 时电池断开供电，拔掉时电池接管
- 充电饱和 4.24V，最大 62℃

⚠️ 充电 + 播放 + 显示同时进行时总电流可能超 500mA，注意 Type-C 线材规格。

## 文档矛盾与坑

这些是我在交叉验证时实际发现的问题，踩之前先看：

### 1. I²S 数据方向：GPIO6 vs GPIO8 ⚠️ 最重要

厂商三份资料说法不一致：

| 来源 | GPIO6 | GPIO8 |
|---|---|---|
| 原理图网络名 | `I2S_DO` | `I2S_DI` |
| IO 资源分配表 xlsx | 「发送音频数据的输出引脚」 | 「接收音频数据的输入引脚」 |
| ESP-IDF 示例说明 PDF | 「位输入数据信号」 | 「位输出数据信号」 |

**结论（按物理连接定论）**：原理图和 xlsx 用的是**编解码器视角**，PDF 用的是**主控视角**，
两者描述的是同一套接线，只是叫法相反。实际连接是：

```
GPIO6 ── net I2S_DO ── ES8311 pin7 ASDOUT (数据手册标注为 O，ADC serial data output)
GPIO8 ── net I2S_DI ── ES8311 pin9 DSDIN  (数据手册标注为 I，DAC serial data input)
```

所以对 ESP-IDF 的 `i2s_std_gpio_config_t` 而言：
```c
.dout = GPIO_NUM_8,   // 主控发给编解码器 → 喇叭
.din  = GPIO_NUM_6,   // 编解码器发给主控 → 麦克风
```

### 2. 功放型号

wiki 的「产品介绍」和用户手册都写 FM8002E，原理图上 U6 实物是 **SC8002B**。
两者 pin 兼容、功能等价，使能极性一致（高=关断）。看时序/极性时用 FM8002E 手册没问题。

### 3. 屏规格书文件名

wiki 正文写「2.8寸 **QD2803** 屏规格书」，实际文件是 `QD2833-Specifications-A.pdf`，
原理图上 QD1 也标 **QD2833**。wiki 正文是笔误。

### 4. I²C 引脚能不能当普通 IO

wiki 接口表写「此 IIC 接口和电容触摸屏共用，**可做普通 IO 使用**」，
用户手册第 14 页写「IIC_SDA 和 IIC_SCL **不能做普通 IO 使用**」。
实际取决于你用不用触摸/音频——IO 资源分配表的说法最准确：
「不使用触摸和音频功能时可做普通 IO；使用则只能做 I²C」。

### 5. 没有独立的屏复位脚

TFT_RST 直接接 CHIP_PU。想单独复位屏幕做不到，只能整机复位。
移植 BSP 时 `reset_gpio_num` 填 `-1`。

### 6. 小智例程源码包没有本板板级定义

厂商提供的 `小智例程源码.zip` 里是**未经修改的上游 xiaozhi-esp32**
（1.7.6 / 2.0.2 / 2.1.0 三个版本），`main/boards/` 下**没有**针对 ES3C28P 的目录，
全仓库唯一带 FT6336 的是 `m5stack-core-s3`。
要在这块板子上跑小智，得自己照本文引脚写一个 board 定义。
厂商预编译的 bin 在厂商页面的 Quick_Start 包里可以直接烧。

### 7. wiki 把串口 TX/RX 标反了

wiki 接口表写「RXD0(IO43) 接收 / TXD0(IO44) 发送」，方向是反的。
原理图（U7 pin49=U0TXD、pin50=U0RXD）、IO 资源分配表、ESP-IDF 示例说明三者一致：
**IO43 = U0TXD（发送），IO44 = U0RXD（接收）**，也就是 S3 的默认分配。

### 8. 示例源码不在可直接下载的资料里

wiki 上「快速使用资料包」的 zip 里只有**预编译 bin + Windows 版 flash 下载工具**，
不含 Arduino / ESP-IDF / MicroPython 示例源码。
源码在「资料包下载」那三个**网盘链接**（123 云盘 / 百度云）里，需要手动下载：

- <https://www.123865.com/s/Kg5Wvd-7UGr3>
- <https://pan.baidu.com/s/1G3M-Q1ztXdHwf7xHjxnRsQ?pwd=yvne>（提取码 `yvne`）
- <https://1855123618.v.123pan.cn/1855123618/24207552>

厂商示例基于 ESP-IDF **5.4.1** + LVGL **8.4.0**。

### 9. IPS 版 ILI9341 必须开反显

**症状**：界面颜色整体反过来——设计的是白底黑字，屏上显示黑底白字；
白色主按钮变成黑色，黑色图标变成白色。灰阶界面尤其容易忽略，
因为"黑底白字"看起来也像一种正常的深色主题。

**原因**：ILI9341 的 TN 版和 IPS 版出厂极性相反。本模组（QD2833）是 **IPS**，
需要 `INVON`（0x21）；ILI9341 复位后默认是 `INVOFF`（0x20），
`esp_lcd` 驱动也不会替你判断面板类型。

**结论**：

```c
esp_lcd_panel_invert_color(panel, true);   // IPS 版：必须 true
```

2026-09-04 实机确认：改成 `true` 后白底黑字正确显示。

**顺带说明两个曾被误判为硬件故障的现象**——它们都是"黑底亮字"放大出来的观感问题，
反相修正后自然消失，**不是排线接触不良，也不是 SPI 超频**：

| 现象 | 真实成因 |
|---|---|
| 文字有淡淡的位移副本（"重影"） | 亚克力盖板与屏之间有气隙，亮字在盖板上二次反射 |
| 高对比边缘发红/发蓝（"彩边"） | 字库 `--bpp 2` 抗锯齿的灰边经 RGB565 量化（绿 6 bit、红蓝各 5 bit）偏色；143 PPI 的屏被相机怼近拍还会叠加摩尔纹和镜头色差 |

判别方法：白底黑字下这两样都看不出来；要复现只需把背景改成黑色。
