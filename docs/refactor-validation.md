## 改动范围

- 原 `main/ui.c` 3,658 行拆为 312 行协调入口与 9 个 UI 模块。
- 各页面管理自己的控件和销毁过程；应用状态、续播/睡眠策略、偏好存储分别收拢到 `app_radio` / `preferences`。
- Wi-Fi 服务改为状态通知；音频/OTA/Wi-Fi 通知不再从工作任务等待界面锁。
- 页面跳转共用清理路径；异步主题重建重新检查当前页面，保留配网输入与启动过渡保护。
- 交互回归发现并修复两个既有问题：主题预置色点、触摸测试十字线的装饰子对象拦截中心点击。
- 关键任务边界、资源释放、NVS 兼容性均添加中文注释；维护方法见 `architecture.md`。

## 真机回归

设备为 ES3C28P。操作前读取并备份整片 16MB Flash，校验 SHA-256，确认实际分区为独立 Radio OS 双 OTA 布局，当前启动应用位于 `0x20000`。没有改写 bootloader、分区表或 OTA 选择数据。

通过 `tests/device/serial_ui.py`：

- 播放、列表、筛选、设置、关于、诊断、触摸测试、更新、扫描和密码输入页面的导航与板上渲染截图。
- 筛选草稿取消/应用、12/24 小时设置、主题预置色中心点击、选色应用/取消。
- 五点 LVGL 输入注入：平均偏差 `+0,+0`、离散 `0,0`。
- 扫描中途离开页面并切换主题；扫描任务返回后正常运行。
- 12 轮主题切换及按需页面创建/销毁：内部空闲内存从 70,823 到 70,915 字节，PSRAM 均为 5,531,148 字节，没有观察到该轮循环造成的内存减少。
- 睡眠到期停止播放并息屏，取消计时不息屏，唤醒触摸不透传为播放操作。
- 实际 HTTP MP3 播放：44.1kHz、64kbps，PCM 响度与频谱变化；收藏添加/移除，音量拖动不触发换台或暂停。
- 直播测试期间有 1 次缓冲耗尽，随后自动恢复播放；本次没有做多小时弱网稳定性测试。

截图来自开发板上的 LVGL 渲染，触摸由测试输入驱动注入。它们验证页面/事件链路，不等同于摄像头观察实体面板、真实手指校准或人工听音。没有重新提交 Wi-Fi 密码或执行 OTA 安装。
